# Freenpipe desktop app

The Tauri desktop app for Freenpipe: timeline, search, chat, pipes, connections and settings. It starts the engine and talks to it over the local API.

Build steps for Windows are in [docs/dev/windows-build.md](../../docs/dev/windows-build.md); macOS and Linux steps are in [CONTRIBUTING.md](../../CONTRIBUTING.md). User documentation is in [docs/mintlify/docs-mintlify-mig-tmp](../../docs/mintlify/docs-mintlify-mig-tmp/getting-started.mdx). Read [TESTING.md](../../TESTING.md) before changing window management, the tray, monitors or audio.
