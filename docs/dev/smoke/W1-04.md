### W1-04 Enterprise and plan-gate no-op surface

- [ ] **SMK-W1-04-1** (UI smoke) The enterprise and plan-gate commands answer for a personal install from the running app
  - Setup: installed screenpipe quit; `scripts/dev/app-dev.sh` (dev app on port 3035 with a throwaway `FP_DD`); a network monitor optional (Resource Monitor's Network tab or `netstat -b`).
  - Steps: 1. Open the main window's devtools (right click, Inspect) and go to the Console. 2. Run `const inv = window.__TAURI_INTERNALS__.invoke;` 3. Run, one at a time: `await inv("is_history_access_restricted")`, `await inv("apply_enterprise_ui_visibility")`, `await inv("get_enterprise_host_identity")`, `await inv("list_managed_team_skills")`, `await inv("set_enterprise_recording_authorized", {authorized: false, credentialType: "license_key", credential: "ENT-0000-0000-0000-0000"})`, `await inv("sync_managed_team_skills", {skills: [{name: "x"}], pruneUnlisted: true})`, `await inv("set_activity_sync_enabled", {enabled: true})`. 4. Check the app log (`$FP_DD` logs folder) for the credential string.
  - Expected: the answers are `false`, `false`, `{machine_id_hash: null, os_user_id_hash: null}`, `[]`, then `null` three times (no error); recording keeps running after step 3 and the tray and windows stay visible; `ENT-0000` does not appear in any log; no outbound connection is opened by the app while running the commands.
