# W2-23 Windows smoke checks

### W2-23 Pi runtime 0.84.1, isolated config, baseline bun, compaction patch

All entries use the isolated dev app: quit the installed screenpipe, `source scripts/dev/dev-env.sh smoke`
(port 3035, focus port 11436, `FP_DD`), then `scripts/dev/app-dev.sh`. "The app log" is the newest
`screenpipe-app.*.log` in `$FP_DD`. Start each entry from an empty `$FP_DD` unless it says otherwise, and
note the modification time of `%USERPROFILE%\.pi\agent\models.json` and `settings.json` beforehand if
they exist (Freenpipe must never change them).
