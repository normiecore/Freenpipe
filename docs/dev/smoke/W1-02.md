- [ ] **SMK-W1-02-1** (UI smoke) A fresh install writes the v2 defaults into the dev data dir
  - Setup: installed screenpipe quit; `source scripts/dev/dev-env.sh smoke` with a fresh `FP_DD` (no `store.bin`).
  - Steps: 1. `scripts/dev/app-dev.sh` and let the app reach onboarding. 2. Quit it. 3. Open `$FP_DD/store.bin` in a text editor.
