## setup

<Steps>
  <Step title="start Freenpipe">
    start the desktop app you built, or run `screenpipe record` from the CLI build. see [getting started](/getting-started).

    grant screen recording and microphone permissions when prompted, and Freenpipe starts capturing.

    <Tip>on macOS, you'll need to allow screen recording and accessibility access in System Settings → Privacy & Security.</Tip>
  </Step>

  <Step title="let it record for 2 minutes">
    browse some websites. write some code. check slack. Freenpipe captures app text, primarily via accessibility APIs with OCR as the fallback, and transcribes audio.

    you can verify it's working:
    ```bash
    curl http://localhost:3030/health
    ```
  </Step>

  <Step title="connect your AI">
    pick your AI tool and connect Freenpipe to it:

    **Claude Desktop (recommended)**
    open Freenpipe → go to **settings** (gear icon, bottom of sidebar) → **connections** (under Data & Privacy) → click **"install extension"** next to Claude.

    **Claude Code**
    ```bash
    claude mcp add screenpipe --transport stdio --scope user -- npx -y screenpipe-mcp
    ```

    **Codex**
    open Freenpipe → go to **settings** → **connections** → click **connect** next to Codex. then open a new Codex session.

    **Cursor**
    [click here to install in cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=screenpipe&config=eyJ0eXBlIjoic3RkaW8iLCJjb21tYW5kIjoibnB4IiwiYXJncyI6WyIteSIsInNjcmVlbnBpcGUtbWNwIl19)

    **ChatGPT**
    in the Freenpipe chat (Home), click the model selector next to the input → select **ChatGPT** → sign in with your OpenAI account.
  </Step>

  <Step title="ask your first question">
    go to your AI tool and try:

    - *"what was I working on in the last 5 minutes?"*
    - *"summarize what I just read in the browser"*
    - *"what apps have I been using?"*

    your AI can now query your screen history.
  </Step>

  <Step title="run your first pipe">
    pipes are AI automations that run on a schedule. Freenpipe ships with built-in template pipes; go to **settings → pipes** to enable and run one.

    good first pipes:

    | pipe | what it does |
    |------|-------------|
    | **Day Recap** | today's accomplishments, key moments, and unfinished work |
    | **Standup Update** | a copy-paste standup report |
    | **Time Breakdown** | where your time went, by app, project and category |
    | **AI Prompt Journal** | collects the prompts you send to AI tools into a journal |

    pipes need an AI provider: your own API key, or a local model through [Ollama](/ollama). [built-in pipes and writing your own →](/pipe-store)
  </Step>
</Steps>

## common first questions

**"what are pipes?"**
pipes are scheduled AI agents that run on your screen data. a pipe can summarize your day, track your time, sync notes to Obsidian, or do anything else you can describe in a prompt. manage them in **settings → pipes**. [learn more →](/pipes)

**"is my data private?"**
yes. everything is captured and stored locally. no data leaves your machine unless you choose a cloud AI provider, a connected app, or a remote AI workflow. Freenpipe sends no telemetry. see [privacy data flow](/privacy-data-flow).

**"can I use my own AI subscription?"**
yes. you can use your ChatGPT Plus or Claude Pro subscription, or any API key. you can also use local models through Ollama, so nothing leaves your machine. [learn more →](/chatgpt)

**"what does Freenpipe capture?"**
screen text (primarily via accessibility APIs, with OCR fallback), audio transcriptions, app names, window titles, browser URLs, and user input events. you control what's captured in **settings → recording**.

**"how do I connect my apps?"**
go to **settings → connections** (under Data & Privacy). integrations include Slack, Notion, Gmail, Google Calendar, Obsidian, Toggl, HubSpot, Salesforce, PostHog, Sentry and Zoom. [learn more →](/connections)

**"how do I know it worked?"**
open **Home**, ask a question in your AI tool, or run `curl http://localhost:3030/health`. after a few minutes of recording, `/search` and [API recipes](/api-recipes) should return real activity.
