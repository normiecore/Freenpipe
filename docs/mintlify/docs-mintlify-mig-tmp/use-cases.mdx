Handvel captures your screen and audio and makes it available to AI. this page lists what you can do with it, organized by what you are trying to accomplish.

---

## choose your first workflow

*Handvel gets more useful when you give it a concrete job. start with one workflow, one person, and one week of evidence.*

| if you are... | start with | success looks like |
| --- | --- | --- |
| individual founder or operator | daily recap plus open-loops summary | you can ask "what did I do today?" and get useful next steps |
| developer using Claude, Codex, or Cursor | MCP memory for recent terminal, browser, and meeting context | your AI can recover what you were doing before context loss |
| team lead | SOP capture for one repeated workflow | one clean process doc from real screen activity |
| sales or customer success | meeting summary plus follow-up draft | transcript, screen context, objections, and next email in one place |
| team pilot | one or two test machines, one repeated workflow, clear privacy filters | the pilot user gets a useful output |

the best first prompt is usually:

```markdown
Search the last 24 hours of screenpipe data.
Summarize what mattered.
Include:
- work completed
- meetings and decisions
- blockers
- open loops
- suggested next actions
```

## close your loops

*find where you left off on a task, across apps and projects.*

- **ask AI**: "what was I working on before lunch?" → get the exact file, app, and context
- **ask AI**: "what was that API endpoint I was looking at in Chrome yesterday?" → find it instantly
- **run Day Recap pipe**: get a daily summary of accomplishments, unfinished work, and what to do next
- **search by time**: `curl "http://localhost:3030/search?start_time=2026-04-10T09:00:00Z&end_time=2026-04-10T12:00:00Z"`

**best setup:** connect Claude Desktop or Cursor via MCP → ask natural language questions about your screen history.

## turn real work into SOPs

*support, finance, operations, and QA workflows are often trapped in someone's hands. Handvel turns one good run into a draft process.*

- **record one clean pass**: open the same tools you normally use and complete the workflow once
- **ask for a step-by-step SOP**: include systems used, decisions, exceptions, and evidence links
- **review with a teammate**: mark anything the AI guessed or missed
- **turn it into a pipe**: run the same summary after each repeated workflow

example prompt:

```markdown
Search the last 60 minutes of screenpipe data.
Create a training doc for a new teammate.
Use the screen text, transcript, app names, and timeline moments.
Flag any step that needs human verification.
```

**best setup:** desktop app + audio recording + [MCP](/mcp-server) or a custom [pipe](/pipes).

## never miss a meeting detail

*search what was said in your meetings, with speaker labels and timestamps.*

- **search transcriptions**: "what did John say about the deadline?" → find the exact quote
- **run the Meeting Summary pipe**: AI summaries of the meeting that just ended, with action items
- **speaker identification**: Handvel identifies who said what; name a speaker once and later meetings use that name
- **search by speaker**: `curl "http://localhost:3030/search?content_type=audio&speaker_name=John"`

**best setup:** enable audio recording in settings → enable the [Meeting Summary pipe](/pipe-store).

## track your time automatically

*see how your time splits across apps and windows, based on recorded activity.*

- **run Time Breakdown pipe**: see exactly how many hours you spent in each app
- **write a Toggl pipe**: auto-log time entries based on active apps, with your Toggl key in the pipe's `.env` ([pipes](/pipes))
- **productivity score**: pipes can calculate focused work time vs. context-switching time
- **by project**: AI groups related activities into projects automatically

**best setup:** run [Time Breakdown](/pipe-store) for on-demand analysis, or write a pipe that posts to Toggl for automatic tracking.

## write standups and reports

*draft standup updates and reports from the work you recorded.*

- **run Standup Update pipe**: generates "what I did / what I'm doing / blockers" in under 150 words
- **weekly reports**: create a custom pipe that summarizes your week
- **share with team**: copy-paste the output into Slack, Teams, or Discord

**best setup:** go to **settings → pipes** → enable Standup Update → run it every morning before standup.

## build a personal knowledge base

*what you have seen on your screen, searchable for as long as you keep the data.*

- **write daily summaries to Obsidian**: [connect Obsidian](/obsidian) and run a daily summary pipe
- **run the AI Prompt Journal pipe**: capture every prompt you send to ChatGPT, Claude, etc.
- **keep memories**: pipes can save what they learn about your work as memories you can search later
- **search by app, URL, time range, or speaker**: find what you have seen or heard

**best setup:** [Obsidian](/obsidian) + the [AI Prompt Journal pipe](/pipe-store).

## give AI memory of your screen

*let AI tools search your screen and audio history through MCP.*

- **Claude Desktop**: ask "what was I working on?" and Claude searches your screen history via MCP
- **Cursor**: give Cursor context about what you've been coding, what PRs you reviewed, what errors you saw
- **Claude Code**: search your screen history from the terminal
- **ChatGPT**: use your ChatGPT subscription inside Handvel's built-in chat

**best setup:** add Handvel MCP to your main AI tool → [setup guide](/mcp-server).

## recover from AI context loss

*when an AI chat compacts or a coding agent loses earlier context, it can search your recorded history instead.*

- **recent activity**: "what did I do in the last 20 minutes?"
- **terminal recovery**: "find the error I saw in Terminal before the chat reset"
- **meeting memory**: "what did the customer ask for on the last call?"
- **browser trail**: "what docs page was I reading before I switched apps?"

Handvel does not recover hidden model context. it gives the AI a local, searchable memory of screen and audio history.

**best setup:** connect the tool you already use through [MCP](/mcp-server), then ask it to cite Handvel results before acting.

## monitor your AI usage

*how much time are you actually spending in ChatGPT vs. Claude? are you using AI effectively?*

- **run AI Habits pipe**: see which AI tools you use, for how long, and for what
- **track prompt patterns**: the AI Prompt Journal shows your prompting habits over time
- **identify tool overlap**: are you using 3 tools for the same thing?

**best setup:** run AI Habits pipe weekly.

## manage relationships

*remember everyone you meet, what you discussed, and when to follow up.*

- **relationship notes**: a pipe can build relationship context from your screen and audio data after each call
- **CRM sync**: a pipe can detect business calls and write contacts, deal stage, and action items to Notion or another CRM you connect
- **follow-ups**: a pipe can draft the follow-up email after a meeting

**best setup:** [connect](/connections) your CRM or notes app, then write a pipe for it ([pipes](/pipes)).

## monitor a specific app or window

*some users want Handvel to watch a narrow surface: a dashboard, trading terminal, ticket queue, internal tool, or customer app.*

- use included windows so only the target app is captured
- start with `content_type=all`, then narrow to `accessibility` or `ocr` if needed
- add a pipe that checks every few minutes and only alerts on a precise condition
- test the notification path separately before trusting the automation

example:

```markdown
Every 5 minutes, search the last 10 minutes of screenpipe data for the window named "Operations Dashboard".
If a red error banner or failed status appears, send a desktop notification and write a short incident note.
If no matching data appears, log "no matching window data" instead of guessing.
```

**best setup:** [recording filters](/troubleshooting) + [pipe debugging](/pipe-debugging).

## automate anything

*pipes are scheduled AI tasks that read your recorded data and act on it.*

ideas for pipes:

- **focus assistant**: detect when you're distracted and send a notification
- **CRM sync**: write business calls to your Notion CRM
- **research helper**: dig into topics you're browsing and collect sources
- **voice notes**: import recordings from another app as memories

ask your AI coding tool: "create a Handvel pipe that [what you want]" ([full guide →](/pipes)).

## for teams

*standardize workflows across a team.*

- **share pipes**: a pipe is one file, so a team can keep its pipes in a shared git repository
- **agree on filters**: document the window and URL ignore lists everyone should use
- **team standups**: everyone runs the same standup pipe, formatted the same way
