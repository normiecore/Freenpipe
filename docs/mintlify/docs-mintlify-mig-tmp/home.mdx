Freenpipe records your screen and audio, stores everything locally, and makes it available to AI. you can search what you have seen, automate workflows with pipes, and give AI assistants access to your screen history.

Freenpipe is an MIT fork of screenpipe at commit `892199f`, working toward feature parity with screenpipe v2.7.104 through clean-room work. it has no release yet: you build it from source (see [getting started](/getting-started)). project status is in [STATUS.md](https://github.com/normiecore/Freenpipe/blob/main/docs/clean-room/STATUS.md).

## what Freenpipe does

- **captures screen and audio**: screen text via accessibility APIs with OCR fallback, audio transcription, app names, browser URLs, user input
- **runs locally**: data stays on your machine in `~/.screenpipe/`
- **search**: find what you have seen or heard through the app, an AI assistant, or the API
- **pipes**: scheduled AI agents that summarize your day, track time, sync to Obsidian, and more ([built-in pipes](/pipe-store))
- **MCP server**: give Claude, Cursor, ChatGPT, and other AI tools access to your screen history ([setup](/mcp-server))
- **connect your apps**: integrations such as Slack, Notion, Gmail, Obsidian, Toggl, HubSpot, Salesforce, Zoom, PostHog and Sentry ([connections](/connections)), configured in **settings → connections**

## common use cases

| I want to... | how |
|---|---|
| **find something I saw on screen** | search in the app, ask your AI, or `curl localhost:3030/search?q=...` |
| **get a summary of my day** | run the [Day Recap pipe](/pipe-store) |
| **auto-track my time** | run the [Time Breakdown pipe](/pipe-store), or write a pipe that posts to Toggl |
| **transcribe meetings** | automatic: use [meeting intelligence](/meeting-intelligence), search audio, or run the Meeting Summary pipe |
| **give Claude memory of my screen** | [connect via MCP](/mcp-server) |
| **sync activity to Obsidian** | [connect Obsidian](/obsidian) and enable the sync pipe |
| **close my loops** | ask your AI "what was I working on before lunch?" ([use cases](/use-cases)) |
